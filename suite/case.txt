# Unicode 18.0.0 default case conversion, untailored.
#
# Source:
#   Raoh catalog/operations.json — toLowerCase, toUpperCase
#   Souther specification.adoc — string-case
#   199x-notation README.md — What belongs here (the bounded forms)
#
# text ; direction ; bound ; outcome ; mapped
#
# direction is LOWER or UPPER. bound is empty for a conversion without one, and otherwise the most
# scalar values the mapped text may hold. outcome is MAPPED, with the mapped text, or PAST where the
# mapped text is longer than the bound, with mapped empty.
