# text ; form ; bound ; outcome ; normalized
#
# form is NFC, NFD, NFKC or NFKD. bound is the most scalar values the normalized text may hold.
# outcome is NORMALIZED, with the normalized text, or PAST where that is longer than the bound,
# with normalized empty. Normalization without a bound is held to ucd/18.0.0/NormalizationTest.txt,
# and every normalized text here is the one that file states for the text. Each is held at the
# bound it fills exactly and one below it.
