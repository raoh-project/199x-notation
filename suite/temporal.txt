# The lexical grammar of dates, times, date-times, date-times with an offset, and instants.
#
# Source:
#   Raoh catalog/operations.json — date, time, dateTime, offsetDateTime, instant
#   Souther specification.adoc — temporal-text, a-leap-second-is-no-moment
#
# kind ; text ; outcome ; reason
#
# kind is DATE, TIME, DATETIME, OFFSET_DATETIME or INSTANT. outcome is ADMITTED or REFUSED. reason is
# empty for ADMITTED. For REFUSED it is LEAP_SECOND for an instant whose fields exist but for a second
# of 60, MALFORMED for any other text, and empty where the sources do not decide between the two.

# Second 60 names a leap second, which is refused where it is written and where it arrives. Where the
# rest of an instant exists that is the reason. A second of 60 in a day that does not exist, or in a
# time, a date-time or a date-time with an offset, is refused, and the sources do not say which
# reason it is.
