# Images of P2 and text that is not one, and what each image accepts.
#
# Source:
#   image/P2.md — What an image is written in, The numbers in order, What makes an image one, What an image accepts
#
# image ; subject ; outcome
#
# image is the text as it is, in printable ASCII, but for a space and any character outside printable
# ASCII, each written <U+XXXX> with its scalar value in hex: so a line can hold an image with a space
# or a line break at either end, which a line otherwise drops. subject is a text as its scalar values
# in hex, as in suite/. outcome is ACCEPTED or NOT_ACCEPTED for an image and the
# subject, or REFUSED for text that is not an image of P2, whose subject is empty. Every line is
# written by hand from image/P2.md, not by a writer.

# a+: class 0 is every scalar value but a, in two pieces, and class 1 is a.
